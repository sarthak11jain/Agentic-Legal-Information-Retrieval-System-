# Competition archive (2026)

This directory preserves the original Kaggle research scripts, prompts, and
experiments. It is retained for provenance, not maintained as a public package
interface.

The archive may require authorized competition data, large local artifacts,
credentials, GPUs, and provider-specific services. Install optional dependencies
with `python -m pip install -e ".[archive]"` only when you have authorization
to use those materials. Do not treat archive outputs as legal advice or commit
generated data, submissions, or credentials.
