# Reproduction levels

## Supported package

Install the package and run `legal-rag-demo`. This is fully local and uses only
bundled synthetic data.

## Historical competition work

The archive documents an earlier research environment. Reproducing it requires
authorized competition data, precomputed artifacts, optional archive
dependencies (`python -m pip install -e ".[archive]"`), and selected model
providers. It is not expected to run from a clean checkout.
