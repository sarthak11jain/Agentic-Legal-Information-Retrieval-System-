# Experiment summary

The original competition work improved the documented public Macro F1 from
0.17058 to 0.27569 through graph expansion, conservative reranking, and an LLM
confirmation stage. The final private leaderboard score was 0.22252, ranking
44th of 584 teams.

Raw commands, provider-specific settings, and exploratory notes belong to the
`competition-2026` release/archive because they require restricted data and
external services. They are not instructions for the maintained package.
