# Release checklist

- [ ] Working tree is clean and CI is green.
- [ ] README links, CLI commands, and package build are verified.
- [ ] No secrets, competition data, hidden labels, derived labels, or generated submissions are included.
- [ ] Any score claim records source URL, commit, configuration, backend/model, split, and metric.
- [ ] Changelog and version are updated; a signed release/tag is created.
- [ ] GitHub description, topics, social preview, branch protection, and private vulnerability reporting are configured.
